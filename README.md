# Decodelabs_task2_student.grade.calculator
The Student Grade Calculator is a robust console-based Java application designed to automate academic performance evaluation.

Goal: 
Build an efficient Java application that computes the total marks, average percentage, and final letter grade for a student.  

📋 Key Requirements & Features

>Multi-Subject Input: Safely accepts marks (out of 100) for any specified number of subjects. 

>Automated Calculations: Instantly aggregates cumulative total marks and computes the precise average percentage. 

>Conditional Grading System: Evaluates the overall percentage against standard grading tiers to assign a corresponding letter grade.  

>Clean Result Presentation: Formats and displays a comprehensive summary of the student's marks and final grade.  

⚙️ Key Concepts

>ImplementedJava Variables and Data Types 

>Iterative Control Structures (For Loops)   

>Arithmetic Operations  

>Conditional Statements (if-else branching)
